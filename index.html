Laboratory Activities

Practical Learning Through Mobile Development

Lab 1 - UI Design

This lab introduced the fundamentals of Jetpack Compose and Android user interface development. I learned how to build layouts, arrange components, and create visually appealing mobile screens.

Lab 2 - Interaction

This lab focused on user interaction and state management. I implemented interactive components and learned how Android applications respond dynamically to user actions.

Lab 3 - Material Design

I explored Material Design 3 principles and modern UI components. This lab improved my understanding of consistency, usability, and professional interface design.

Lab 4 - Navigation

This lab introduced Android Navigation and multi-screen applications. I learned how to connect pages and create a seamless user experience across screens.

Lab 5 - Room Database

This lab focused on local data persistence using Room Database. I learned how to create entities, DAOs, and databases to manage application data efficiently.

Projects

Applying Mobile Development Skills in Real Applications

Project 1 - Study Buddy

Problem Statement:
Many university students struggle to organize their study materials, schedules, and academic tasks efficiently. Study Buddy was developed to provide a centralized platform that helps students organize academic information and improve productivity.


Study Buddy Project 1 introduced multiple screens connected through Android Navigation and implemented Room Database to store and manage study-related information. Users can add, edit, and view study records while sharing data across different pages.


View on GitHub

Project 2 - Study Buddy

Problem Statement:
Students often need a more engaging and interactive learning environment. Study Buddy was enhanced with cloud synchronization and interactive features to improve the overall learning experience.


Project 2 integrates Firebase Firestore, Android sensors, and cloud services. Users can generate motivational quotes by shaking their devices, while cloud storage allows data synchronization and accessibility across different sessions.

Reflection & Learning Journey

From Beginner to Mobile Application Developer

Throughout this Mobile Programming course, I gradually progressed from designing simple user interfaces to developing complete Android applications with database, navigation, cloud, and sensor integration.


Each laboratory session introduced new concepts that expanded my technical skills and understanding of mobile application development. The two projects allowed me to apply theoretical knowledge in practical scenarios while solving real-world problems.


Project 1 strengthened my understanding of Room Database, Navigation, and multi-screen application design. Project 2 challenged me to integrate Firebase Firestore, cloud synchronization, and Android sensors into a single application.


Overall, this learning journey significantly improved my confidence, programming skills, problem-solving abilities, and understanding of modern Android application development using Kotlin and Jetpack Compose.
